Module 01

Hilbert Space & Statevector Representation

$\mathbb{C}^{2^n}$ Complex Vector Space

For an $n$-qubit register, the quantum state $|\psi\rangle$ lives in a $2^n$-dimensional Hilbert space $\mathcal{H} = (\mathbb{C}^2)^{\otimes n}$. The state is represented as a normalized column vector of complex probability amplitudes $c_i = a_i + i b_i \in \mathbb{C}$:

MATHEMATICAL FORMULATION 
|ψ⟩ = ∑_{i=0}^{2^n - 1} c_i |i⟩  ∈  ℂ^(2^n)

Born Normalization Constraint:
  ⟨ψ|ψ⟩ = ∑_{i=0}^{2^n - 1} |c_i|² = ∑_{i=0}^{2^n - 1} (Re[c_i]² + Im[c_i]²) = 1.0

Measurement Probability of basis bitstring |k⟩:
  P(k) = |⟨k|ψ⟩|² = |c_k|² = c_k* · c_k
💡 Physical Meaning: In a 3-qubit register, the simulator continuously maintains $2^3 = 8$ complex values spanning $|000\rangle \dots |111\rangle$. When any single gate is applied, the matrix transformation acts on all 8 amplitudes simultaneously, enabling quantum parallelism.

Module 03

Density Matrix Formalism & Partial Trace

$\rho = |\psi\rangle\langle\psi| \text{ and } \rho_A = \text{Tr}_B(\rho_{AB})$

For a pure state $|\psi\rangle$, the full density operator $\rho = |\psi\rangle\langle\psi|$ contains all observable quantum information. The diagonal elements $\rho_{ii} = |c_i|^2$ represent population probabilities, while off-diagonal elements $\rho_{ij} = c_i c_j^*$ represent quantum coherence.

DENSITY MATRIX & PARTIAL TRACE COMPUTATION 
Properties of Density Operator ρ:
  1. Hermiticity:          ρ = ρ†
  2. Unit Trace:           Tr(ρ) = ∑_i ρ_ii = 1.0
  3. Positive Semi-Definite: ⟨φ|ρ|φ⟩ ≥ 0 for all |φ⟩
  4. Purity Measure:       γ = Tr(ρ²)   (γ = 1 for pure states, γ < 1 for mixed states)

Von Neumann Entropy (Quantum Information Entropy):
  S(ρ) = -Tr(ρ log₂ ρ) = -∑_i λ_i log₂ λ_i    (λ_i = eigenvalues of ρ)

Partial Trace for Subsystem A (Tracing out Subsystem B):
  ρ_A = Tr_B(ρ_AB) = ∑_k (I_A ⊗ ⟨k|_B) ρ_AB (I_A ⊗ |k⟩_B)
🔬 Observation: If Qubit 0 is maximally entangled with Qubit 1 (e.g. in a Bell state), its reduced density matrix is $\rho_0 = \text{diag}(0.5, 0.5)$, yielding $S(\rho_0) = 1.0$ bit and purity $\gamma = 0.5$. This confirms that local subsystems of an entangled pure state appear completely mixed.
Module 04

Pauli Observable Expectation Values

$\langle X \rangle, \langle Y \rangle, \langle Z \rangle \in [-1, +1]$

For any single-qubit subsystem described by reduced density matrix $\rho_i = \begin{pmatrix} \rho_{00} & \rho_{01} \\ \rho_{10} & \rho_{11} \end{pmatrix}$, its 3D Bloch sphere vector $(r_x, r_y, r_z)$ is given directly by the expectation values of the Pauli observables:

OBSERVABLE EXPECTATIONS 
Z Expectation (Population Difference):
  ⟨Z⟩ = Tr(Z · ρ_i) = ρ₀₀ - ρ₁₁ = P(|0⟩) - P(|1⟩)

X Expectation (Real Coherence / Transverse Polarization):
  ⟨X⟩ = Tr(X · ρ_i) = ρ₀₁ + ρ₁₀ = 2 · Re[ρ₀₁]

Y Expectation (Imaginary Coherence):
  ⟨Y⟩ = Tr(Y · ρ_i) = i(ρ₀₁ - ρ₁₀) = -2 · Im[ρ₀₁]

Bloch Radius (State Purity Indicator):
  |r| = √(⟨X⟩² + ⟨Y⟩² + ⟨Z⟩²) ≤ 1.0
  • |r| = 1.0  ⟹ Pure state on the surface of the Bloch sphere
  • |r| < 1.0  ⟹ Mixed state inside the Bloch sphere (decohered or entangled)
Module 05

Decoherence & Lindblad Master Equations

$T_1$ Energy Relaxation & $T_2$ Phase Dephasing

Physical qubits in quantum processors (such as superconducting transmons or trapped ions) interact with thermal and electromagnetic environmental baths. Ananta models open-system dynamics using the Lindblad master equation:

OPEN QUANTUM SYSTEM DYNAMICS 
Lindblad Master Equation:
  dρ/dt = -i/ℏ [H, ρ] + ∑_k ( L_k ρ L_k† - ½ {L_k† L_k, ρ} )

1. Longitudinal Energy Relaxation (T₁):
   Jump operator: L₁ = √(1/T₁) · |0⟩⟨1| = √(1/T₁) · σ⁻
   Excited state population decay: ρ₁₁(t) = ρ₁₁(0) · e^(-t / T₁)

2. Transverse Dephasing (T₂):
   Jump operator: L_φ = √(1 / 2 T_φ) · Z
   Total dephasing rate: 1/T₂ = 1/(2 T₁) + 1/T_φ   ⟹  T₂ ≤ 2 T₁

3. Depolarizing Channel (Gate Infidelity ε):
   E(ρ) = (1 - ε) ρ + (ε / 3)(X ρ X + Y ρ Y + Z ρ Z)

Module 07

Entanglement Metrics & Wootters Concurrence

Quantifying Two-Qubit Inseparability

For a 2-qubit bipartite state $\rho$, Ananta calculates **Wootters Concurrence** $C(\rho) \in [0, 1]$, where $C = 0$ corresponds to an unentangled product state and $C = 1$ indicates a maximally entangled Bell pair:

WOOTTERS CONCURRENCE DERIVATION 
Spin-Flipped Density Matrix:
  ρ̃ = (σ_y ⊗ σ_y) · ρ* · (σ_y ⊗ σ_y)

Eigenvalues of R = √(√ρ · ρ̃ · √ρ):
  Sorted in descending order: λ₁ ≥ λ₂ ≥ λ₃ ≥ λ₄ ≥ 0

Concurrence:
  C(ρ) = max(0, λ₁ - λ₂ - λ₃ - λ₄)

Entanglement of Formation:
  E_F(ρ) = h( ½ (1 + √(1 - C²)) ),   where h(x) = -x log₂ x - (1-x) log₂ (1-x)
Module 08

Quantum Teleportation Protocol Pipeline

1 Bell Pair + 2 Classical Bits $\implies$ State Transfer

Transfers an unknown state $|\psi\rangle_A = \alpha|0\rangle + \beta|1\rangle$ from Alice to Bob using a pre-shared Bell state $(|00\rangle + |11\rangle)/\sqrt{2}$ without transmitting physical matter:

STEP-BY-STEP MATHEMATICAL TELEPORTATION PROOF 
Initial 3-Qubit State:
  |Ψ₀⟩ = (α|0⟩ + β|1⟩)_A ⊗ (1/√2)(|00⟩ + |11⟩)_BC

1. Alice applies CNOT(A → B):
  |Ψ₁⟩ = (1/√2) [ α|0⟩(|00⟩ + |11⟩) + β|1⟩(|10⟩ + |01⟩) ]

2. Alice applies Hadamard on Qubit A:
  |Ψ₂⟩ = ½ [ |00⟩(α|0⟩ + β|1⟩) + |01⟩(α|1⟩ + β|0⟩) + |10⟩(α|0⟩ - β|1⟩) + |11⟩(α|1⟩ - β|0⟩) ]

3. Alice measures qubits A and B, obtaining classical outcomes (m_A, m_B):
  • 00 ⟹ Bob applies I         (State: α|0⟩ + β|1⟩)
  • 01 ⟹ Bob applies X         (State: α|0⟩ + β|1⟩)
  • 10 ⟹ Bob applies Z         (State: α|0⟩ + β|1⟩)
  • 11 ⟹ Bob applies Z · X = Y (State: α|0⟩ + β|1⟩)
Module 09

Grover's Search & Amplitude Amplification

$\mathcal{O}(\sqrt{N})$ Provable Quadratic Speedup

Searches an unstructured space of $N = 2^n$ items for a target marked item $|w\rangle$ in $\mathcal{O}(\sqrt{N})$ queries using geometric rotations in a 2D subspace:

GROVER OPERATOR DEFINITION 
Grover Iteration Operator:
  G = -D · O = (2|s⟩⟨s| - I) · (I - 2|w⟩⟨w|)

Where:
  |s⟩ = (1/√N) ∑ |x⟩        (Uniform equal superposition)
  O = I - 2|w⟩⟨w|           (Phase oracle: marks target |w⟩ by -1)
  D = 2|s⟩⟨s| - I           (Diffusion operator: reflection about the mean)

Optimal Number of Rotations:
  R = ⌊ (π / 4) · √(N / M) ⌋
  • For N=4 (2 qubits), M=1 ⟹ R = 1 iteration achieves 100% success probability!
Module 10

VQE & Parameter-Shift Rule Gradients

Analytical Hardware Gradients Without Finite Differences

The Variational Quantum Eigensolver (VQE) minimizes molecular Hamiltonian expectation values $E(\theta) = \langle\psi(\theta)|H|\psi(\theta)\rangle \ge E_0$. To perform gradient descent on physical noisy quantum processors, the **Parameter-Shift Rule** computes exact analytical partial derivatives:

PARAMETER SHIFT RULE FORMULA 
Rayleigh-Ritz Variational Principle:
  E(θ) = ⟨ψ(θ)| H |ψ(θ)⟩ ≥ E_ground

Parameter-Shift Rule (Exact Analytical Derivative on QPU):
  For any parameterized rotation gate G(θ) = exp(-i θ P / 2) with Pauli P:
  ∂E / ∂θ_i = ½ [ E(θ + (π/2) e_i) - E(θ - (π/2) e_i) ]

Key Advantage:
  Unlike classical finite differences (E(θ+h) - E(θ))/h which drown in quantum shot noise,
  parameter shifts evaluate at macroscopic ±π/2 angles, robust against hardware stochasticity.

📐 Threshold Theorem & Error Scaling

In a rotated surface code, the logical error rate scales exponentially with distance below threshold $p_{th} \approx 1\%$:

$$p_L \approx C \left(\frac{p}{p_{th}}\right)^{\frac{d+1}{2}}$$
